# Native remote deployment connection

Manager calls a fixed packaged, SHA-bound public Node 24.21.0 runtime and the reviewed public Deployment adapter. Build preparation verifies the official release archive checksum and includes Node and Apache license notices. No GUI-controlled executable or script is accepted. The original Windows desktop build remains supported, with manual remote deployment fallback.

The server form requires the existing closed Generic SSH OED, operator-confirmed known_hosts identity/hash, server Manager executable/hash, private deployment root and HTTPS origin. Only declared environment/OS-keychain references are resolved by the public adapter; credential contents are not form fields, persisted requests, logs or returned receipts. Status and logs contain bounded codes/state only. DNS/TLS observations do not provision DNS or firewall.

Backup/update/full-original rollback use existing native Linux commands and current live authority. Update requires the atomic operation/generation native command pair; no legacy fallback. Server-side key/archive/artifact locations are references, not file contents. Explicit preserve-data, existing-images, external-writers-quiesced and apps-closed consent is required before maintenance writes. Changed-schema, signature, recovery, health and selection validators remain authoritative. No paid cloud apply is invoked.

One owned request is active at a time. The app prevents close while its worker is active; an explicit cancel requests graceful SSH abort, then a bounded hard stop if necessary. Cancel, connection failure and timeout are uncertain outcomes: inspect current server status/logs before retry. Update uses a fixed 41.5-minute caller deadline; backup/full-original rollback 31.5 minutes, allowing adapter cleanup. No user-selected timeouts or arbitrary commands.

Source fixtures/native compile do not prove actual remote server deployment. Actual server/domain, credential-expiry/partial apply, interruption/resume and Linux full update/rollback qualification remain separately reported.
