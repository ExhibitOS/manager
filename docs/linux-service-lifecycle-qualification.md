`scripts/qualify-linux-service-lifecycle.mjs` is a trusted CI test, not an operator recovery command or changed-schema permit. It requires Linux, a non-root caller, EXHIBITOS_DISPOSABLE_LINUX_RUNTIME_CHECK=1, canonical RUNNER_TEMP, an independently built Manager CLI path, public Platform source path and a verified exact maintenance image ID. It creates a unique private synthetic namespace; no existing user root/key/archive or retained signed operation is adopted or replayed.

The public Platform packager builds the actual runtime/archive/Compose manifest, and Manager executes install/start/stop/restart. Actual HTTP login/CSRF/anonymous denial, CMS artist/artwork creation and asynchronous deterministic GLB import are exercised. After real stop/restart and restart readiness, Manager pauses its own Platform writer while keeping the database available, then creates and authenticates an encrypted service backup using a newly generated private32-byte external key. Independent authentication uses the installed Manager and a separate fresh private copy of its cipher input because maintenance refuses input/output path overlap; original cipher bytes/modes remain checked and untouched. The temporary input is included in the cumulative runner budget. It restores into a new root and loopback port, then verifies real readiness/login/artist/blob digest/exact signing key ID and public key/private denial. The authority origin must equal the deliberate new loopback port; unchanged signing identity is not a claim that existing origin-bound frozen grants remain usable. Every original cipher file byte/mode, external key and source environment bytes must remain unchanged, and both exact installations must finish stopped.

No credentials, cookie, CSRF value, key content, connection string or raw process failures enter the report. Completion requires both exact typed success receipts and persisted terminal job state. HTTP requests close connections to avoid reusing a pre-restart socket. Failure reports retain the granular stage and safe code, without converting failed/interrupted jobs into success. The script does not delete volumes, originals, archives or failed candidates. Disposable-runner lifecycle controls only newly generated synthetic test data; do not run against production or user data. Maintain the full summed peak and6GiB floor before launching it. CI remains manual public standard Ubuntu without hosted caches/artifact upload/paid external service.

Compilation/syntax/fixture review does not qualify actual execution. Even a pass does not prove full frozen-corpus coverage, changed migration/activation/publication crash windows, public changed-schema admission, actual native GUI/VoiceOver, Windows/device/signing, external HTTPS exhibition deployment or whole release acceptance.
