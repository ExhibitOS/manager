It creates a unique private synthetic namespace; no existing user root/key/archive or retained signed operation is adopted or replayed.

Actual HTTP login/CSRF/anonymous denial, CMS artist/artwork creation and asynchronous deterministic GLB import are exercised. The temporary input is included in the cumulative runner budget. It restores into a new root and loopback port, then verifies real readiness/login/artist/blob digest/exact signing key ID and public key/private denial.
